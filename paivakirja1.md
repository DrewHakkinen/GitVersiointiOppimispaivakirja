# Oppimispäiväkirja: Paikallinen git

__Mikä osion tehtävissä oli vaikeaa ja mikä helppoa? Mikä auttoi minua oppimaan? Miten selvitin esteet?__

Edellisissä kurseissa on tullut gittiä käytettyä, joten add, status ja commit ovat tuttuja. Olen juuri myös käynyt Linux palvelimet kurssin, joten Git Bashissa komentojen käyttäminenkin oli suhteellisen tuttua.

Vaikeaa oli aluksi ymmärtää peruutuksia ja muokkausten poistoja. Missä kohti voi tehdä resetin ja missä revertin. Kokeilemalla ja katsomalla selätettiin ne ongelmat.

Branchien käyttö ei ollut vaikeaa, vaikka luulin että se olisi ollut jotenkin monimutkaisempi juttu. Ennenkuin lähdin tekemään tehtäviä halusin katsoa päiväkirjaa ja se oli virhe. En osannut vielä vaihtaa brancheja ja olin jumissa siinä miten saa tämän edes näkyviin. Sitten kun menin materiaaleihin, löysin ohjeet.

## Osiossa käyttämäni Git-komennot

| Komento | Kuvaus |
| --------| ------ |
| Git clone | Komento kloonasi minulle oman version reposta |
| ls -la | Katsotaan mitä hakemistossa on |
|status | Näyttää projektin tilanteen |
| touch | Luo uuden tiedoston |
| nano | Avaa nanon, jossa voi muokata tiedostoa|
| add | Lisää muutokset talletukseen|
| commit | Varsinainen talletus|
| cat | Näyttää mitä tiedostossa on |
| code . | Avaa projektin vs codessa |
| mv | Muokkaa tiedoston nimeä tai siirtää tiedoston|
| rm | Poistaa tiedoston |
| log | Näyttää mitä on tullut tehtyä |
| tag | Nimeää viimeisimmän muutoksen |
| revert | Peruuttaa yhden talletuksen kerrallaan |
| reset | Peruuttaa kaikki lisätyt muutokset talletuksesta |
| branch | Luo uuden haaran|
| switch | Vaihtaa haaraa|
| merge | Yhdistää haarat|
