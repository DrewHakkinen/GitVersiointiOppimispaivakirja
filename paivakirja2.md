# Oppimispäiväkirja: Hajautettu git

__Mikä osion tehtävissä oli vaikeaa ja mikä helppoa? Mikä auttoi minua oppimaan? Miten selvitin esteet, jotka vaikuttivat tehtävän suorittamiseen?__

Repositorion luominen GitHubiin oli helppoa, koska sitä on tehty edellisillä kursseilla. Git fetch ja Git pull oli helpottava tehdä, koska kursseilla ne tehdään aina, että ollaan ajantasalla etärepojen kanssa. Edellisissä tehtävissä tuntui oudolta, kun ei synkattu etärepon kanssa.

Tässä osiossa ei ollut mitään erityisen vaikeaa, koska paikallisen repon ja etärepon kanssa työskentely ja synkkaus on jo hyvin tuttua. Tätä kurssia olisi kyllä kipeästi tarvittu Johdanto digitaaliisiin palveluihin -kurssin ohella.

Opin kyllä uusia komentoja ja miten nimetä etärepo Git Bashista käsin.

## Osiossa käyttämäni Git-komennot

| Komento | Kuvaus |
| --------| ------ |
| branch | Haaran luomiseen / haarojen tarkistamiseen |
| switch | Haaran vaihtamiseen |
| touch | tiedostojen luomiseen |
| add | muutosten lisääminen talletukseen |
| commit | muutosten tallettaminen |
| status | tilanteen seuranta |
| push | muutosten vieminen etärepoon |
| remote | etärepon tarkistaminen |
| fetch | muutosten hakeminen etäreposta |
| pull | helpompi muutosten hakeminen etäreposta |
| merge | haarojen/muutosten yhdistäminen |
| log | mitä on tullut tehtyä |
| tag | tehtävä muutosten tagaus |
